PIX Recebimentos

Política de Privacidade
Última atualização: 05 de outubro de 2026

1. Objetivo

Esta Política de Privacidade explica como o aplicativo PIX Recebimentos trata as informações utilizadas durante seu funcionamento.

O aplicativo foi desenvolvido para permitir o cadastro local de dados do recebedor, geração de códigos PIX, compartilhamento de códigos PIX e controle local de registros de recebimentos.

2. Dados utilizados pelo aplicativo

O aplicativo pode armazenar localmente no dispositivo:

  • nome do recebedor;
  • cidade do recebedor;
  • chave PIX cadastrada;
  • identificador TXID, quando informado;
  • descrições de cobranças;
  • valores e datas/horários de registros de recebimentos;
  • status manual dos recebimentos, como pendente ou pago;
  • uma senha utilizada para proteger a área de gerenciamento dentro do aplicativo.

Essas informações são utilizadas para executar as funções do próprio aplicativo.

3. Armazenamento local

Os dados de configuração, registros de recebimentos e senha são armazenados no armazenamento local do navegador/WebView do dispositivo. O aplicativo não possui, no código analisado, uma rotina própria que envie esses dados para um banco de dados ou servidor do desenvolvedor.

Os dados locais podem ser perdidos quando o armazenamento do aplicativo for apagado, quando o aplicativo for desinstalado ou quando o usuário limpar os dados do aplicativo/navegador.

4. Dados que o aplicativo não coleta diretamente

Na versão analisada, o aplicativo não implementa coleta própria de:

  • localização GPS;
  • s;
  • microfone;
  • câmera;
  • fotos ou vídeos da galeria;
  • número de telefone do aparelho;
  • conta bancária;
  • credenciais de acesso a bancos;
  • senha de aplicativos bancários;
  • dados de cartão de crédito;
  • dados de autenticação do usuário em um servidor próprio.

O aplicativo também não possui, na versão analisada, publicidade personalizada ou compras dentro do aplicativo.

5. PIX e instituições financeiras

O aplicativo gera localmente o conteúdo de uma cobrança PIX a partir dos dados informados pelo próprio usuário. Ele não acessa diretamente a conta bancária do usuário e não confirma automaticamente uma transação bancária.

O status de um recebimento é registrado manualmente pelo usuário no relatório do aplicativo. O aplicativo não deve ser interpretado como comprovante bancário ou como confirmação automática de pagamento.

6. Copiar e compartilhar

Quando o usuário escolhe copiar o código PIX, o aplicativo utiliza os recursos de área de transferência do dispositivo. Quando o usuário escolhe compartilhar, o código é encaminhado ao mecanismo de compartilhamento do sistema, que permite ao usuário escolher o aplicativo de destino.

O desenvolvedor não controla o tratamento realizado pelo aplicativo escolhido pelo usuário após o compartilhamento. Recomenda-se verificar a política de privacidade do serviço de destino.

7. Serviços e bibliotecas de terceiros

A versão analisada utiliza bibliotecas públicas carregadas por HTTPS a partir da rede de distribuição de conteúdo (CDN) cdnjs, incluindo a biblioteca usada para geração do QR Code e recursos de interface.

Ao carregar esses recursos, o dispositivo pode realizar uma conexão com o serviço responsável pela CDN. Como em qualquer conexão de internet, informações técnicas necessárias à comunicação, como endereço IP, navegador/WebView e dados de conexão, podem ser processadas pelo respectivo provedor de infraestrutura de acordo com suas próprias políticas.

8. Segurança

O aplicativo utiliza HTTPS para carregar seu conteúdo e armazena seus dados funcionais localmente no dispositivo.

Importante: a senha de gerenciamento da versão atualmente analisada é armazenada no armazenamento local do dispositivo. Ela não deve ser reutilizada como senha de banco, e-mail ou outro serviço. O usuário deve proteger o próprio aparelho contra acesso não autorizado.

9. Compartilhamento de dados

O desenvolvedor não vende nem aluga os dados armazenados localmente pelo aplicativo. Como o aplicativo não possui, na versão analisada, um servidor próprio para receber esses dados, não há compartilhamento automático desses dados com o desenvolvedor.

O usuário pode, entretanto, optar voluntariamente por compartilhar um código PIX com terceiros usando os recursos de compartilhamento do sistema.

10. Direitos e controle do usuário

O usuário controla os dados armazenados localmente pelo aplicativo e pode editar ou excluir registros por meio das funções disponíveis no próprio aplicativo. O usuário também pode apagar os dados locais do aplicativo pelas configurações do Android ou desinstalar o aplicativo.

11. Privacidade de crianças

O aplicativo não é direcionado especificamente a crianças e não foi desenvolvido para solicitar deliberadamente dados pessoais de crianças.

12. Alterações desta política

Esta Política de Privacidade poderá ser atualizada quando houver alterações no aplicativo, nos serviços utilizados ou nas exigências legais e das plataformas de distribuição. A data de atualização será modificada quando uma nova versão da política for publicada.
